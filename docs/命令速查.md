# 命令速查

只列 FF14 相关。所有命令默认前缀 `#`，`[]` 表示可选，`<>` 表示必填。

## 灰机 wiki

| 命令 | 说明 |
|---|---|
| `#f <关键词>` | 查副本 / 物品 / 任务 / NPC 攻略 |
| `#查询` `#ff14` `#wiki` | `#f` 的同义命令 |

先走官方搜索 API，没结果再逐命名空间直接抓正文。一个关键词约 10~30 秒。

## FFLogs 战绩

| 命令 | 说明 |
|---|---|
| `#fflogs <服务器> <角色名>` | 出图：7 个绝本（含全部历史版本）+ 暗黑之云 + 当前大版本零式 |

- 服务器用中文名（`白银乡` / `红玉海` / `旅人栈桥`…）
- 角色名要和 FFLogs 上完全一致，繁简、空格都算
- 每行：Best / 最高 RDPS / Kills / 全明星积分与排名 / 最快击杀
- 没打过的副本也占一行标「未通关」，不会整行消失
- 单用户 20 秒冷却，数据缓存 10 分钟

## 市场物价

| 命令 | 说明 |
|---|---|
| `#市场 <物品名> [hq]` | 国服前五个最便宜的区服：价格、在售数量 |
| `#市场 <物品ID>` | 用 itemID 查（新物品名字还没进索引时用这个） |
| `#市场更新` | 检查是否有新物品（无变化不下载） |
| `#市场更新 强制` | 强制重建中文物品索引 |

输出格式：`世界名（大区）  价格 金  ×数量  在售 N  HQ xxx`

## BIS 配装

| 命令 | 说明 |
|---|---|
| `#bis <职业>` | 该职业最新 BIS 配装链接 |
| `#bis <职业> <关键词>` | 按版本 / 副本名 / 类型过滤，如 `7.4零式`、`伊甸 BIS`、`神兵`、`绝妖` |
| `#bis检测` | 查源文档是否有新版本 |
| `#更新bis` | 重新解析本地 xlsx |

职业写法：坦克（战士/骑士/暗骑/绝枪）、治疗（白魔/学者/占星/贤者）、龙骑、镰刀、武僧、武士、蝰蛇、忍者、机工、诗人、舞者、画家、赤魔、召唤、黑魔。

俗称：`绝妖` = `绝凯夫卡`。

## 网站导航

| 命令 | 说明 |
|---|---|
| `#查网站` | 列出 14 个分类及各分类站点数 |
| `#查网站 <需求>` | 模糊搜索，返回最相关的 6 个站点（名称 / 简介 / 链接） |

关键词直接写需求即可：`物价`、`配装`、`房子`、`战斗记录`、`幻化`。每人 5 秒冷却。

## 国服公告推送

| 命令 | 说明 |
|---|---|
| `#查看ff14最近新闻` | 立刻看最近 5 条官方公告（不订阅也能用，30 秒冷却） |
| `#开启ff14新闻推送` | 有新公告自动推送到本群 / 私聊（每两小时的第 10 分钟查一次） |
| `#关闭ff14新闻推送` | 关掉本群 / 私聊的推送 |

推送范围是 `8324,8325,5310` 三个分类：维护/异常/功能开停公告 + 最新情报（版本更新笔记、季节活动、联动、商城周边）。

推送以**合并转发**发出，标题一个节点、每条公告一个节点。

## 随机幻化

| 命令 | 说明 |
|---|---|
| `#随机幻化` | 随机一套，出图 + 全套装备与染色（约 0.5~0.8 秒，冷却 10 秒） |
| `#随机幻化 拉拉肥` | 指定种族，靠客户端重刷，最多 8 次（约 0.5~4.5 秒，冷却 30 秒） |

种族可写：`人 / 精灵 / 拉拉肥（土豆、矮子）/ 猫娘（猫、猫猫、喵）/ 鲁加（大块头、巨人）/ 龙娘（龙、龙族）/ 大猫（硌狮、狮子）/ 兔娘（兔、兔兔）`，也可直接发数字 `1`~`8`。

> 用 `rising-stones` 已绑定的账号，没绑先发 `#石之家` 登录。
